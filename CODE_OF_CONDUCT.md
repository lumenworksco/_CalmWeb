# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, discrimination and personal attacks are not tolerated.

Because the project is about student wellbeing, please also take extra care with discussion of mental health: no stigmatising language, and no graphic descriptions of self-harm.

## Reporting

To report a violation, use GitHub's private channel: open a [private security advisory](https://github.com/lumenworksco/_CalmWeb/security/advisories/new) and mark it as a conduct report. Maintainers will review it confidentially.
