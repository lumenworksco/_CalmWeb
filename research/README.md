# Research evidence

Backing for the claims on the website. Version 1.0 of the dossier is `CalmCampus-Evidence-Dossier.pdf` (also linked from the site's Research section).

- `index.csv`: all sources with DOI, design, key finding, limitations, verification status
- `NOTES.md`: what was verified, what was left out, and why
- `research_log.md`: which number came from which source
- `download_papers.sh`: re-downloads the open-access papers into `papers/` (gitignored: third-party copyright)
